# 截图资源目录 (Screenshots)

存放已压缩的现代化 WebP 格式实机截图（由原图压缩 90%+，保持视网膜高清分辨率与微秒级网络加载速度）：

1. `desktop_home.webp` - Windows 桌面端首页（今日推荐、每日放送周历与继续追番卡片，1600x880）
2. `desktop_player.webp` - Windows 桌面端播放器（沉浸式播放、满屏弹幕、选集与快捷键，1600x880）
3. `mobile_home.webp` - Android 移动端首页（流线响应式布局与磨砂胶囊底部导航，720x1600）
4. `mobile_player.webp` - Android 移动端播放详情（置顶硬解播放、弹幕与多线路切换，720x1600）
